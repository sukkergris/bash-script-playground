# Basics — Fundamentale Linux/Bash-koncepter

Dette er den selvstændige "Basics" sektion for fundamentale ting du skal kunne for at arbejde effektivt med Linux og Bash.

**Vigtig:** Basics er IKKE en udvidelse af bash-30-dage planen. Det er fundamentale IT-koncepter som går på tværs af alle programmering.

---

## Sektioner

### [Installation](installation/)
Hvordan man installerer programmer på Linux-systemer.

**5 metoder:**
1. [apt-get (package manager)](installation/opgaver/opgave-1-apt.sh)
2. [GitHub releases (pre-compiled binary)](installation/opgaver/opgave-2-github.sh)
3. [Kompilering fra kilde](installation/opgaver/opgave-3-compile.sh)
4. [Shell script installer](installation/opgaver/opgave-4-script.sh)
5. [Manuelt download + PATH](installation/opgaver/opgave-5-manual.sh)

Alle øvelser bruger **fzf** som praktisk eksempel.

Se [installation guide](installation/guide.md) for teori og sammenligning af metoder.

## Kommende sektioner

- **Filsystem** — navigering, permissions, links
- **Tekstbehandling** — cat, head, tail, less
- **Hjælp og dokumentation** — man pages, info, --help
- **System-information** — uname, lsb_release, df, du
- **Scripting-basics** — shebang, chmod +x, $PATH
- **Terminal-tricks** — aliaser, funktioner, history
