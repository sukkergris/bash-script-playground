# Extension 2 — jq (JSON parser)

**GitHub:** https://github.com/jqlang/jq

**Hvad er det?**
`jq` er et command-line JSON processor. Det lader dig parse, filter, transform og manipulere JSON data på samme måde som du bruger pipes i bash.
