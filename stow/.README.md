# stow

Denne mappe bruges som et **GNU Stow-pakke-træ** — en struktureret måde at administrere dotfiles og programmer via symlinks.

## Hvad er GNU Stow?

Stow opretter symlinks fra en kildemappe til en målmappe (som standard forældreren, altså `/xyz`). Strukturen inde i `stow/` afspejler præcis den stistruktur, du ønsker på målstedet.

```
stow/
└── bin/
    ├── myprogram   →  symlinkes til /xyz/bin/myprogram
    └── program     →  symlinkes til /xyz/bin/program
```

## Brug

Kør fra `/xyz/stow/`:

```bash
# Opret symlinks for alle pakker
stow *

# Opret symlinks for en specifik pakke (mappe)
stow bin

# Fjern symlinks
stow -D bin

# Simuler uden at ændre noget (dry run)
stow -n bin
```

## Indhold

| Fil | Beskrivelse |
|-----|-------------|
| `bin/program` | Simpelt "Hello world" program |
| `bin/myprogram` | Tom placeholder til eget program |

## Typisk arbejdsflow

1. Placer filer i `stow/` med den ønskede mappestruktur
2. Kør `stow <mappenavn>` for at symlinke dem på plads
3. Filen er nu tilgængelig via symlinket og kan redigeres ét sted
